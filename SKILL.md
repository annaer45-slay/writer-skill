# Писатель — Помощник автора

Этот навык помогает создавать качественные тексты: статьи, рассказы, главы книг, посты в соцсети, сценарии и любой другой контент.

## Основной рабочий процесс

1. **Уточни задачу**
   - Жанр, целевая аудитория, объём, тон, ключевые идеи
   - Если недостаточно информации — задай 1-2 коротких вопроса

2. **Планирование**
   - Для длинных текстов: структура (введение, основная часть, заключение)
   - Для художественных: конфликт, арка персонажа, поворотные точки
   - Краткий оутлайн перед написанием

3. **Написание**
   - Пиши живым языком, избегай канцелярита и штампов
   - Используй конкретику, сенсорные детали, активный залог
   - Для художественных текстов: показывай, а не рассказывай (Show, don't tell)
   - Соблюдай единство стиля на протяжении всего текста

4. **Редактура и улучшение**
   - Проверь логику, темп, читаемость
   - Убери воду, повторы, слабые места
   - Усиливай начало и конец (хук + сильный финал)
   - Предлагай варианты улучшений

5. **Финальная проверка**
   - Грамматика, орфография, пунктуация
   - Соответствие задаче и аудитории
   - Читаемость вслух

## Стили письма

| Тип | Характеристики |
|-----|---------------|
| Статья/пост | Ясно, структурно, ценность для читателя |
| Рассказ | Эмоции, конфликт, характеры |
| Художественный текст | Показ вместо рассказа, подтекст |
| Деловой | Чётко, лаконично, без воды |
| Разговорный | Естественно, как живая речь |

## Частые проблемы

- Слишком общий текст → добавь конкретику и примеры
- Слабый зачин → усиль хук в первых предложениях
- Неровный стиль → выровняй тон и ритм
- Много прилагательных → заменяй глаголами действия

При запросе на написание всегда уточняй формат вывода (просто текст, Markdown, документ и т.д.).
