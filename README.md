# Writer Skill (Навык Писатель)

Навык для Grok, который помогает писать и редактировать тексты (статьи, рассказы, главы книг, посты и т.д.).

## Как использовать

1. Скачай репозиторий или скопируй содержимое в папку навыка.
2. В Grok: Skills → New Skill → Upload skill file (можно зазиповать папку), или помести файлы в `.grok/skills/writer/`.
3. Активируется на запросы вроде «напиши статью», «помоги сочинить рассказ», «отредактируй этот текст», «разработай сюжет».

Файлы:
- `SKILL.md` — основные инструкции
- `CHANGELOG.md`
- `evals/` — тестовые кейсы

Репозиторий: https://github.com/annaer45-slay/writer-skill
